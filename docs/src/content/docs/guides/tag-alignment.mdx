A real field element can be a few centimeters from where the field map says. `TagGoal` measures the stopping spot
from the tag the camera actually sees.

<Scene name="tag" caption="The faint tag is where the field map puts it. The solid robot switches to the spot measured from the real tag and stops square to it. The gap is far larger than a real field is off, so that it shows. Run by the Java library on a simulated drivetrain, with the tag sighting supplied by the scene." />

The drive has two goals. Until the camera has locked on, it heads for the field map's spot. Once locked, its end
follows the spot measured from the tag.

## Make the goal

```java
// Where to stop, in the tag's own frame: 45 cm out from the tag's face, facing it
TagGoal reefTag = new TagGoal(new Transform2d(0.45, 0.0, Rotation2d.PI));
```

| Part of the transform | Meaning |
| --- | --- |
| +X | Out of the tag's face, meters |
| +Y | To the tag's left, meters |
| Rotation of 180° | Facing the tag |

## Feed it sightings

Call this every time a camera frame shows the tag.

```java
// Returns false when it skipped the sighting: too far away, or a jump from the current estimate
reefTag.add(tagInRobot, odometryAtCapture, now);
```

| Argument | Meaning |
| --- | --- |
| `tagInRobot` | The tag's pose as the camera saw it, in the robot's frame, with the camera's own corrections already applied |
| `odometryAtCapture` | The robot's pose from wheels and gyro only, at the moment the picture was taken |
| `now` | The current time, seconds |

:::caution
`odometryAtCapture` is the **wheel-only** pose, the one vision never corrects, at the time of the photo. Your
drivetrain has to keep a short history of it. See
[What your drivetrain provides](/start/drivetrain/#optional-extras).
:::

## Build the command

```java
Command align = otf.toTarget(drive, () -> mapGoal)          // sets off for the field map's spot, real field frame
    // Once the tag is locked, the end follows the measured spot. fieldGoal is empty until then.
    .withMovingGoal(() -> reefTag.fieldGoal(drive.getOdometryPose(), drive.getPose()))
    .finishWhen(() -> reefTag.hasLock())                    // does not finish on the map's guess
    .withTolerance(0.02, Rotation2d.fromDegrees(1));
```

In an autonomous, add a timeout to the command.

## Good to know

- **Call `reefTag.reset()`** when a new approach starts, so an old estimate is not reused.
- **Use the plain `withMovingGoal`**, without a smoothing time. `TagGoal` has already filtered the sightings.
- **`fieldGoal(odometryNow, fieldNow)` takes two poses.** When vision corrects the field pose, the robot and the
  goal move together.
- **Your code keeps the camera.** It reads it, chooses the tag, applies the mounting corrections, and rejects a
  frame that is too old or too ambiguous.

## What the filter does

| Behavior | Detail |
| --- | --- |
| Smooths | A Kalman filter on each axis. Sightings from further away count for less. |
| Ignores a stray | One sighting that disagrees with the estimate is skipped. |
| Locks | `hasLock()` is true once three sightings agree. |
| Reports | `secondsSinceSeen(now)` and `tagPose()` are there for logging. |

:::note
The filter's noise numbers came from one robot's cameras, not yours. Watch a still tag in a log and compare the
spread before trusting 2 cm.
:::
