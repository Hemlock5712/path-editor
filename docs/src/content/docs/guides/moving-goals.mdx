A **moving goal** ties the end of a path to a pose your code supplies each loop. When that pose moves, the
library re-plans the rest of the path to it.

<Scene name="tag" caption="A drawn path whose end is bound to a goal 1 m out from a tag that is not where the map put it. The faint robot is the same path with no goal bound. Run by the Java library on a simulated drivetrain." />

## Bind a goal

```java
// A drawn path whose end follows vision
Command score = otf.follow(drive, Paths.TO_SCORE)
    .withMovingGoal(() -> vision.scoringPoseIfSeen());

// An on-the-fly path whose end follows vision
Command grab = otf.to(drive, guess)
    .withMovingGoal(() -> vision.pieceIfSeen());
```

The supplier returns an `Optional<Pose2d>`.

- **A pose** is the goal now, in the **real field frame**. It is not flipped on red.
- **Empty** means no new estimate. The library keeps the last goal.

## Smooth a raw camera goal

```java
// Averages the estimates over 0.5 s, so the robot does not chase camera jitter
Command grab = otf.to(drive, guess)
    .withMovingGoal(() -> vision.pieceIfSeen(), 0.5);
```

| Form | Use it for |
| --- | --- |
| `withMovingGoal(supplier, 0.5)` | A goal that arrives raw from a camera. The estimates are averaged over that many seconds. |
| `withMovingGoal(supplier)` | A goal that is already filtered, such as a [TagGoal](/guides/tag-alignment/). It is followed as given. |

:::note
The average trails a moving goal by about its speed times the smoothing time: half a meter at 0.5 s and 1 m/s.
A rolling target has not been tested.
:::

## Hold the finish

```java
Command align = otf.toTarget(drive, () -> mapGoal)
    .withMovingGoal(() -> tagGoal.fieldGoal(drive.getOdometryPose(), drive.getPose()))
    .finishWhen(() -> tagGoal.hasLock());   // drive to the goal and hold there until this is true
```

:::caution
A command with `finishWhen` never finishes if the condition never comes true. Give it a timeout in the
autonomous.
:::

## When it re-plans

| When | What happens |
| --- | --- |
| The goal moves more than 2 cm or 2° | The rest of the path is planned again: one smooth piece from where the robot is on the path to the goal, ending at the path's end speed. |
| The last 30 cm | The follower drives straight at the latest goal. |
| On an on-the-fly path, the goal moves more than 10 cm from where the path was planned to | The whole route is planned again, round the obstacles, at most every 0.2 s. |

## Good to know

- **A drawn path's re-planned piece knows nothing about obstacles.** Use an on-the-fly path for a goal that might
  move round one.
- **A raw goal jitters.** On the bench, a tag alignment with 2 cm of noise never settled.
- **A stray estimate is ignored.** With averaging on, one more than 25 cm or 20° from the average counts as a new
  goal only once three in a row agree.
