## Choose the flip

The frame is the last argument to `Pathfinding`, and to the `FollowPathCommand` constructor.

| Frame | Use it when | What it does to a pose |
| --- | --- | --- |
| `FieldFrame.RED_HALF_TURN` | The field looks the same after a half turn about its center | `(x, y, heading)` becomes `(-x, -y, heading + 180°)` |
| `FieldFrame.RED_MIRROR` | The field is mirrored across its center line | `x` becomes `-x` and the heading becomes `180° - heading` |

Set the same choice in the editor, under Settings, Project.

## Know what is flipped

Something you authored is written for blue and is flipped. Something measured on the field is not.

| You give the library | Frame | Flipped on red |
| --- | --- | --- |
| A drawn path | Blue | Yes |
| `otf.to(drive, pose)` | Blue | Yes |
| `otf.toPoint(drive, Points.X, heading)` | Blue | Yes |
| The start of a path in `otf.thenFollow` | Blue | Yes |
| `otf.toTarget(drive, supplier)` | Real field | No |
| A moving goal | Real field | No |
| The measured pose and velocity | Real field | No |
| Obstacles in `field.json` | Real field | No |

## Force an alliance

```java
// For tests. On otf it applies to every command built afterward.
otf.withFrame(() -> FieldFrame.RED_HALF_TURN);
```

`withFrame` on a single command applies to that command. `Conversions.allianceFrame(redFrame)` is the default
lookup, if you want to wrap it.

## Good to know

- **The alliance is read when a command starts**, not when it is built. An unknown alliance counts as blue.
- **The path is never rebuilt for red.** The follower converts the pose and velocity each loop, so red follows the
  plan you saw in the editor.
- **The drive method must not apply an operator perspective.** The library's output is always a field velocity.
- **Teleop is different.** Your teleop command turns the sticks into field directions itself. See
  [Teleop limiter](/guides/teleop-limiter/).

:::caution
On WPILib 2027 alpha-7 and alpha-8 the robot's pose is still measured from the blue corner. That conversion is
separate from the alliance flip, and both apply. See
[What your drivetrain provides](/start/drivetrain/#the-field-frame).
:::
