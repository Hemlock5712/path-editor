An **event** is a named mark on a path. When the robot passes it, the library runs the command you bound to that
name.

<Scene name="events" caption="Three events on one path. Each diamond lights up on the loop the robot passes it. Real follower, simulated drivetrain." />

## Add an event

In the editor, open the path's **Events** tab and place an event at a waypoint or at a distance. Give it a name,
such as `intakeDown`. Save.

## Bind it to a command

Do this once, in robot init. A binding covers every path that uses the name.

```java
import static frc.robot.PathEditorNames.*;

paths.bindEvent(Events.INTAKE_DOWN, intake.lower())   // Events.X is generated from the name
     .bindEvent(Events.SHOOT, shooter.shoot())
     .requireAllEventsBound();                        // a forgotten event fails here, at boot
```

Commands from `otf.follow` and `otf.thenFollow` pick these up on their own.

:::tip
Always end with `requireAllEventsBound()`. Without it, an event nobody bound does nothing, and you find out
mid-match.
:::

## Bind it for one path only

```java
// Wins over the library's binding, for this command
Command toReef = otf.follow(drive, Paths.TO_REEF)
    .onEvent(Events.SHOOT, shooter.shootLow());
```

## When it fires

| Where the event is | When it fires |
| --- | --- |
| Along the path | The loop the robot passes it |
| At the end of a path that stops | When the robot is within 2 cm and 1° |
| Not reached before the path finishes | At the finish |
| The command is canceled | Never. Unfired events are dropped. |

## Good to know

- **The command runs alongside the path.** The robot does not wait for it.
- **It ends when the path ends.** Start a long action from the autonomous routine, not from an event near the
  end.
- **Events fire in order** along the path, each once.

:::caution
An event's command must not require the drivetrain. The path already holds it.
:::

## Check what fired

| Entry | Meaning |
| --- | --- |
| `/Telemetry/Path/<name>/EventsFired` | The events fired this run, in order |
| `/Telemetry/PathFollower/LastEvent` | The most recent event |
