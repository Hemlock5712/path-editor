## What it does

The library does three jobs, in this order. Robot code calls the third or the second; the first happens once,
when the robot boots.

## Install

Put this file in the robot project's `vendordeps` folder. The project also needs the Commands v3 vendordep and
WPILib 2027 alpha-7.

```text title="vendordeps/Myelin.json"
https://hemlock5712.github.io/path-editor/vendordep/Myelin.json
```

Then load every path the editor saved, once, when the robot starts:

```java title="Robot.java"
import static frc.robot.PathEditorNames.*;

PathLibrary paths = PathLibrary.loadAll();
Pathfinding otf = new Pathfinding(paths, FollowerConfig.defaults(paths.robot()),
    () -> drive.getPose(), () -> drive.getFieldVelocity(),
    velocity -> drive.driveFieldVelocity(velocity), FieldFrame.RED_HALF_TURN);

Command toReef = otf.follow(drive, Paths.TO_REEF);
```

[Install](/start/install/) has every step, and [The first path](/start/first-path/) explains each line.

## Where it stands

This is version 2027.0.0-alpha-2. It passes its unit tests and its end-to-end tests in simulation, and it has been
raced against other followers on the team's simulation bench. **It has not run on a real robot yet.** Numbers on
these pages are the library's defaults or measurements from simulation, and each page says which.
