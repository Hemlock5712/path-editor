The library is a **vendordep**: one JSON file in the robot project's `vendordeps` folder. Gradle downloads the
jar the next time it builds.

## Check what you need

| Requirement | Why |
| --- | --- |
| WPILib 2027 alpha-7 | The library is compiled against it. `Myelin.json` names it as `wpilibYear: 2027_alpha7`. |
| The Commands v3 vendordep | Every command in the library is a Commands v3 `Command`. |
| A swerve drivetrain that reports a pose | The library drives a holonomic robot. See [What your drivetrain provides](/start/drivetrain/). |

## Add the vendordep

<Steps>

1. Download the vendordep file.

   ```text
   https://hemlock5712.github.io/path-editor/vendordep/Myelin.json
   ```

2. Put it in the robot project's `vendordeps` folder.

   ```text
   vendordeps/
     CommandsV3.json
     Myelin.json
     Phoenix6-26.70.0-alpha-2.json
   ```

3. Build. The first build needs a network connection to download `frc.team5712:myelin-java`.

   ```bash
   ./gradlew build
   ```

4. Check it. Add this import to any class and build again.

   ```java
   import frc.team5712.path.wpilib.PathLibrary;
   ```

   You should see: the build passes. If the import is red, the JSON file is not in `vendordeps`, or the build
   could not reach the address in it.

</Steps>

:::note
Copying the file is the method that has been checked. The WPILib VS Code command **Manage Vendor Libraries** has
not been tried yet.
:::

## Make the paths folder

The library reads this folder at boot. Create it now.

```text
src/main/deploy/paths/
```

With an empty folder the library still starts, with no paths, the default robot and an open floor.

## Update to a new version

Replace `Myelin.json` with the new one. A published version never changes, so a fix always ships as a new
version number.

| Version | What changed |
| --- | --- |
| 2027.0.0-alpha-2 | Adds `RailDrive.towardPiece(..., eagerness)`, so a team can set how hard the intake assist turns the driver. |
| 2027.0.0-alpha-1 | The first published version. It stays available. |

## Good to know

- **It is Java only.** There is no native code.
- **It builds offline** after the first build. The jar is in Gradle's cache.
- **The sources are published.** In VS Code, Ctrl-click any library class to read its code.
